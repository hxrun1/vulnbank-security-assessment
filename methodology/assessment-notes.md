# Assessment Notes

## Target

- Application: VulnBank mobile banking application
- APK: `vulnbank3.apk`

## Testing Approach

The assessment used black-box testing with manual validation and security testing tools.

## Tools

- Burp Suite
- MobSF
- Genymotion
- apktools

## Public-Repository Rules

Do not commit:

- Real usernames or passwords
- API tokens
- Private certificates
- Personal email addresses
- Screenshots containing sensitive information
- Internal infrastructure details
- Unredacted customer/account data

The report included in this repository has been sanitized for public portfolio use.
